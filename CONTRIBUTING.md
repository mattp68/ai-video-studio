# Contributing

Use synthetic/redistributable fixtures only. Keep owner data out of code and examples. Run setup, the unit suite and synthetic smoke after meaningful behavior changes. Include regression tests for file boundaries, approval persistence and handoff behavior. Use versioned outputs; do not regenerate personal projects in a pull request.

Keep AGENTS.md and CLAUDE.md pointed at one workflow. Document supported platforms and real validation limits. Security issues belong in a private report. Public contributions should include no private audio, portraits, chat transcripts, account details or third-party reference footage.
