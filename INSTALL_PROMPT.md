# One prompt to get started

Open Codex or Claude Code on your computer and paste:

> Set up AI Video Studio from https://github.com/mattp68/ai-video-studio at tag v0.1.0-beta.6 in a new local folder. Read SETUP.md and AGENTS.md first. Check prerequisites and guide me through any missing system tools with my authorization. Install project-local dependencies, including local transcription on a supported Apple Silicon Mac. Run the tests and full synthetic smoke workflow, report available and unavailable capabilities, and open my local studio. Preserve existing files. Use my own footage, references and accounts; ask before paid services or system-wide changes. Do not publish my work.

The assistant should get the files, read the included guide and run the checks. You may need to authorize prerequisite installation or sign in to a reference website in its connected browser. A missing optional feature should produce an explanation and an alternative, not invented analysis.

Already have the files? Open the extracted/cloned folder and ask the assistant to read SETUP.md and AGENTS.md and complete setup. Keep future chats in that folder so saved decisions remain available. See [the pilot checks](docs/PILOT.md).
