# AI Video Studio

An independent, reusable local workspace for AI-assisted videos, carousels and presentations. Include Projects, a Reference Library with techniques, visual storyboards, exact saved review decisions, media helpers and concise chat handoffs. Users bring their own footage, preferences, references and accounts.

Keep shared Codex/Claude Code instructions, project-local pinned setup, source-backed registration, synthetic validation, explicit platform limits, local service boundaries, licensed fonts and an exact source allowlist. The website organizes work; the assistant edits in chat. Nothing sends to a chat, analyzes media, approves a review or publishes automatically.

Application maintenance follows docs/RELEASE.md: branch, pull request, checks, merge and a numbered release. New installations start empty; upgrades preserve owner collections, footage, techniques, scripts, settings, feedback, approvals and local customizations. The clean public starter is separate from any private production studio.

Current release:0.1.0-beta.2. Shared instructions and update guidance must work in a fresh chat without private conversation history.
