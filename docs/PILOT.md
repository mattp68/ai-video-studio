# Fresh-user pilot

Run this on a fresh checkout/directory with the tester's own accounts, once in Codex and once in Claude Code. No access to the private creator studio should be available.

1. Use only README's setup prompt. Record OS/tool versions, missing tools, elapsed setup and any manual instruction needed.
2. Run tests and smoke; open Projects, actual synthetic storyboard and review video. Preview starts paused/muted. Approve/reopen only this synthetic demo and verify persistence after reload and library reference handoff.
3. Create a new project with the tester's own raw footage/script. Review a tight spoken cut, inspect actual storyboard frames, request one revision, render and review the final.
4. Mark the final approved. Start a new chat from the same folder and verify it resumes from STATUS/approval records and can resolve a copied library reference.
5. Add an external source with honest attribution/access limits. Confirm + selects locally and short copied context contains only links/notes.
6. Confirm owner media/settings are excluded from a release export. Report a failure before announcing compatibility.

Record results in local runtime/pilot-notes.md; it is excluded from releases. Public validation should list only anonymized platform/result summaries. Neither a test script nor a successful current chat counts as a fresh Claude Code or team pilot. No automated messages to the team are part of setup.

Reference intake check:save an original URL with a note in Add reference, reload it, edit the title, and try the same post with tracking parameters. It should open the original card and keep its note. Use Analyze in chat and confirm the assistant updates that same ID after inspecting actual media. Missing access must be reported; a saved-link card must not imply a playable preview or completed analysis.

Analysis-next-step check:after saving, the prominent Analyze in chat panel should be visible and keyboard-focused. Keep browsing, reopen and reload:it stays pending with a Not analyzed badge. Copying must not complete it. Edit details is under More options. Once the assistant saves genuine analysis to that same ID, refresh and verify findings and Copy reference as primary.
