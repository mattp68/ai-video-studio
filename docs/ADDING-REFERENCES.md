# Collect in the studio. Analyze in chat.

Click **Add reference** in Reference Library. Paste the original public link; title, creator and **What caught your eye?** are optional. Save it. The reference opens immediately with **Reference saved. Add the visual context.** and a prominent **Analyze in chat** button. Your note stays with the card. No URL is fetched or downloaded during saving.

## Give the reference some context

Choose **Analyze in chat** to copy a short request with the library link, original URL and saved note. Paste it into Codex or Claude Code working in this folder. The assistant should inspect actual media, enrich that same ID, keep your note, and state access/perception limits. Nothing is sent automatically.

Not ready? Choose **Keep browsing**. The card stays **Not analyzed**, and the analysis panel is still there when you reopen it—even after reloading. Copying the request does not mark analysis complete. Once your assistant saves inspected analysis back to the catalog, refresh the studio to see the findings and the usual **Copy reference** action. An inaccessible source stays pending; it does not acquire invented style notes, sounds or a fake preview. See AGENTS.md and HANDOFF.md.

## Keep the basics useful

Open **More options → Edit details** to change a creator reference’s title, creator or note. **Add notes & copy** is also in More options; an already analyzed reference can be sent for further analysis there. The original URL is fixed; add a separate source if it is a different post. Revision checks reject stale forms so later analysis is not overwritten. Existing previews, observations, examples and source windows are preserved.

An existing original post opens its saved card without replacing its title or notes or announcing a new save. Common Instagram share URLs, YouTube video/Shorts links and TikTok video links are deduplicated by source identity. Short redirect-only links cannot be resolved without visiting their destination; use the original post URL when available.

Creator names entered in the form are user-provided. Verified identities/aliases and source-backed previews can be added during analysis. Existing full-video entries/technique families still use the same registry. Your own finalized work continues through project approvals or chat registration.

Personal references/catalogs, their before-images and metadata journals stay local and are excluded from the starter export. Reference saves share the same protected local storage boundary and lock as checkpoint approvals; saving inspiration never approves a project. If a save is interrupted, follow the existing guarded transaction recovery guidance in style-library/PROJECT-NAVIGATION.md.
